# Reproducibility
Given that the analysis is consequential, and requires that at least 
researchers must be able to reproduce it, I am choosing to do this via two
avenues. The first one is CodeOcean as suggested, but also a simple .Rmd file.
This means that even for researchers who are unable to access the CO-OSL, 
they can run it in a simple RStudio environment.
